# Todo Appliacation

The React Todo App is a simple step-by-step application designed to gain experience in developing and learning new technologies.

The following tools and technologies were used in the development:

1. [_Vite v.8_](https://vite.dev/) - The Build Tool for the Web.
2. [_React v.19.2_](https://react.dev/) - The library for web and native user interfaces.
3. [_Typescript v.6_](https://www.typescriptlang.org/) - JavaScript with syntax for types.
4. [_React Router v.7_](https://reactrouter.com/) - A user-obssessed, standards-focused, multy-strategy router you can deploy anywhere.
5. [_Tailwind CSS v.4.2_](https://tailwindcss.com/) - Rapidly build modern websites without ever leaving your HTML.
6. [_React-Icons v.5.6_](https://react-icons.github.io/react-icons/) - Include popular icons in your React projects easily with react-icons.
7. [_Zustand v.5_](https://zustand.docs.pmnd.rs/learn/getting-started/introduction) - A small, fast, and scalable bearbones state management solution.
